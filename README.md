# Suona

Ein Spiel zum Notenlesen auf der Gitarre, für Kinder und Jugendliche. Mit Luna und Fuzz geht es vom Kinderzimmer auf die grosse Bühne: Noten lesen, Münzen sammeln, Tage in Folge üben.

- Läuft ohne Internet, ohne Werbung und ohne Käufe.
- Profile nur mit Spitzname und Figur. Alle Daten bleiben auf dem Gerät.
- Lehrpläne bestimmen die Reihenfolge der Töne (eingebaut: guitarTALKS, eigene lassen sich anlegen).
- Notennamen deutsch (H, B, Fis) oder international (B, B♭, F♯).

## Herunterladen
Jede Änderung auf `main` wird automatisch gebaut und unter **Releases** bereitgestellt:
- `Suona-Setup.exe`: Installationsprogramm für Windows
- `Suona-Windows.zip`: Windows ohne Installation
- `Suona-Android.apk`: Android-Testversion

Hinweise für die Entwicklung stehen in [CLAUDE.md](CLAUDE.md).
